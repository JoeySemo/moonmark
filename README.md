# Moonmark

The public pages for **Moonmark**, a spoiler-free reading companion for iOS:
tell it where you are in a book and it shows you only what you have already
read.

This repository holds the website only — a landing page and the privacy
policy, served by GitHub Pages. The app itself is not open source and lives
elsewhere.

- [Privacy policy](https://joeysemo.github.io/moonmark/privacy.html)

Moonmark is an unofficial, fan-made companion. It is not affiliated with,
endorsed by, or connected to any author or publisher.
